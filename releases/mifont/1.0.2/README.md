# MiFont 1.0.2

Simple local Windows image-to-font app: upload images, enter a family name,
optionally adjust ink threshold, then generate and download both TTF and OTF.
One automatic job detects/labels/traces letters, completes ASCII95 and builds
the font ZIP with coverage and source notices. Missing glyphs are approximate;
an unknown original font cannot be guaranteed from incomplete images.

Official open-font references may be compared online while images stay local.
Selected OFL source notices travel inside fonts and the ZIP. CPU proposals are
available when reference lookup is unavailable. No cloud credits or GPU needed.
No fonts are automatically installed into Windows. Complete matching app and
Potrace source, Inter OFL and all bundled dependency notices are included.
