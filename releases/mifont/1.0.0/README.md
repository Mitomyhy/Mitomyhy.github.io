# MiFont 1.0.0

Independent local Windows image-to-font workspace. Import screenshots, inspect
and label letter regions, adjust metrics, compare public open-font references,
then export genuine TTF and OTF files. Default character set is Latin ASCII95.
Observed letters stay separate from approximate generated proposals. Unseen
glyphs cannot be guaranteed to recover an unknown original font. Selected OFL
reference fitting includes full source/license notices in fonts and projects.

Open via MITOM Launcher 2026.10.24.9. No GPU, cloud account or credits are needed.
Local OCR is optional; source images are never uploaded. The complete matching
app source and bundled dependency notices are included. Customer images,
projects and research caches are not distributed.
