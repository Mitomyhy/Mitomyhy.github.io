# MITOM Launcher 2026.10.25.7

Automatic authenticated Launcher and installed-app updates, with a signed online
app catalogue so MiFont and Vector Migic releases no longer require rebuilding
Launcher. Compatible Panel installs do not require the newest Launcher merely
because it is advertised. Running Photoshop/Order Studio defers Panel updates.

Panel installation reuses verified cross-version cache, downloads up to three
artifacts concurrently, resumes large interrupted transfers, and reduces repeated
Windows process scans. Disk budgets include actual remaining downloads/staging
and changed installation files. Initial AI model setup still downloads about
1.4 GB, in addition to runtimes; no fixed installation time is promised.

Old executable versions, app projects and account configuration are preserved.
Downloads verify the existing publisher signatures and full SHA-256. Website
metadata and both online Launcher/app channels are released in one commit.
