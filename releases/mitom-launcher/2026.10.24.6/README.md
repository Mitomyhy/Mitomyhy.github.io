# MITOM Launcher 2026.10.24.6

Checks launcher and app updates separately. Choose Update & restart to download
verified bytes and hand over to a healthy new launcher without deleting previous
versions or changing Photoshop/account data. Startup failure leaves the current
launcher open for retry. Vector Migic remains 1.0.2.

Versions through 2026.10.24.5 need one upgrade to this corrected release because
their original signed panel channel still lists launcher 2026.10.22.1. Later
releases use the independent signed launcher channel for in-app updates.
