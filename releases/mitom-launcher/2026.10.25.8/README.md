# MITOM Launcher 2026.10.25.8

Clicking Install/Update while Photoshop or Order Studio is open now queues the
operation instead of reporting an installation error. The interface shows
Waiting for Photoshop and continues automatically after the user saves their
work and closes the application. Launcher remains responsive while waiting.

Manual first-time installation and normal completion/setup are preserved.
Repeated clicks create only one waiting timer. A newer authenticated Panel
release replaces the queued release. Positively identified application guards
can be retried after a complete rollback; real I/O errors and recovery-required
transactions remain visible. No application is closed by the Launcher.

Includes all automatic-update, verified cache and resumable-download changes
from 2026.10.25.7. Existing projects, settings and prior executables are retained.
