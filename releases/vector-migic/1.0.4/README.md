# Vector Migic 1.0.4

Independent local raster-to-vector application for Windows x64.
Logo tracing merges small, weak edge fragments into suitable adjacent inks
before fitting curves. This reduces hardened shadow specks beside lettering
while protecting source-authored thin marks, stable interiors and transparency.
Processing size and default controls remain unchanged. Editable Illustrator AI
paths, SVG/PDF/EPS and batch export remain included.
The source README documents format compatibility and limitations.

Open through MITOM Launcher 2026.10.24.8. An existing 1.0.3 app is offered as an
update. Processing and exports run locally; no credits or remote upload.
The complete source and upstream notices are included. User artwork, proprietary
reference software and private comparison material are not part of this release.
These are independent algorithms; exact Vector Magic parity is not asserted.
