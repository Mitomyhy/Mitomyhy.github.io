# Vector Migic 1.0.3

Independent local raster-to-vector application for Windows x64.
Logo Auto uses a bounded adaptive palette and the precision curve backend,
avoiding thousands of incidental colors and fragmented lettering. Default
controls are supplied by the same engine preset used for fresh conversions.
AI export adds editable classic Illustrator vector paths alongside SVG/PDF/EPS.
The source README documents format compatibility and limitations.

Open through MITOM Launcher 2026.10.24.7. An existing 1.0.2 app is offered as an
update. Processing and exports run locally; no credits or remote upload.
The complete source and upstream notices are included. User artwork, proprietary
reference software and private comparison material are not part of this release.
These are independent algorithms; exact Vector Magic parity is not asserted.
