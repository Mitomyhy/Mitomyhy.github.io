Which apps are available on MITOM?+

Photoshop Panel is available today. More tools will join the lineup as they are released, with upcoming apps clearly marked.

What does the launcher do?+

Use the launcher to install, check and update Photoshop Panel. Choose “Download MITOM Launcher” to get the current release.

Do I need Adobe Photoshop first?+

Yes. Photoshop Panel is an extension for Adobe Photoshop. Install Photoshop first, then use the launcher to install the panel.

Where can I follow new releases?+

Check for updates in the launcher or follow the repositories and releases on MITOM’s GitHub ↗.
