Changes by UOY: selected city ID, names/aliases, WGS84 latitude/longitude,
country/admin codes, population and feature code; combined country/admin
name tables; encoded as compact JSON and gzip. No coordinate correction.
This catalog covers populated places in cities500, not every address,
park, lake, neighborhood or small village. Exact matching only; ambiguous
names require a country/province/state. Use explicit latitude, longitude
for an exact point or a place not in the catalog. Existing validated online
cache entries are preserved; uncatalogued names may use the existing
online lookup when it is reachable. No DNS, proxy or security setting is
changed. Moon Phases still uses its existing online service.

Keep this file with cities500.json.gz when distributing the panel/update.
